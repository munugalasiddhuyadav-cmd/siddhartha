Project #112

StudentLife Hack — Architecture & Demo Walkthrough

1. System Architecture Mapping

Originally scoped as a modular Python CLI/GUI application, this web dashboard implements all core and stretch hackathon requirements client-side:

  • API Layer with Graceful Fallback: Fetches live rates from open.er-api.com with automatic fallback to a deterministic offline rate cache upon timeout or network failure.
  • Defensive Sanitization Engine: Validates inputs in real time against NaN, negative/zero values, and upper boundary limits (> 1,000,000), flagging entries exceeding $5,000 USD equivalent.
  • Local State Persistence: Serializes structured conversion objects to localStorage with schema validation and multi-format export (CSV, JSON, Markdown).

2. Hackathon Demo Script (90 Seconds)

  1. Defensive Validation Demo: Type -50 or abc into the Amount field to showcase instant error prevention, then test 7500 to trigger the amber threshold warning indicator.
  2. Persist & Refresh: Click Convert & Save Record, then reload the browser page to verify state survival in localStorage.
  3. Analytics & Filtering: Use the Inspect Flagged Records banner button or filter by category to see live KPIs and Chart.js visualizations update.
  4. Audit Export & Bulk Import: Export a Markdown summary report or upload a CSV/JSON dataset to inspect the row-by-row validation log.
